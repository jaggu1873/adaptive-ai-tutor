## ✨ THE VISION

Imagine having a personal AI teacher who can explain concepts, interact with you, answer questions and adapt to your learning speed.

**That's what we're building.**

A 3D virtual classroom where an AI-powered human-like teacher transforms traditional learning into an interactive, personalized experience.

## 🚀 KEY FEATURES

| Feature | Description |
|---|---|
| 🧑‍🏫 3D Virtual Teacher | Animated teacher in an interactive classroom |
| 🗣️ Voice Interaction | Spoken lessons and browser-based speech |
| 📚 PDF Learning | Upload, read and teach from educational PDFs |
| 🧠 Intelligent Teaching | AI-powered explanations and question answering (integration planned) |
| 🎯 Adaptive Learning | ANN-based student understanding prediction (development planned) |
| 📝 Smart Assessment | Quizzes, feedback and learning progress |
| 🖥️ Interactive Whiteboard | Visual presentation of concepts and equations |
| 📊 Learning Analytics | Track progress and identify knowledge gaps |

## 🧬 ANN + DEEP LEARNING

This project connects two important areas of Artificial Intelligence:

- **Artificial Neural Networks (ANN):** Predict student understanding using learning performance and assessment data.
- **Deep Learning (DL):** Enable intelligent content understanding, natural-language explanations and multimodal interaction.

The long-term goal is to create a tutor that doesn't just deliver information — it understands how a student learns and adapts its teaching strategy.

## ⚡ RUN LOCALLY

### 1. Clone the repository

```bash
git clone https://github.com/jaggu1873/adaptive-ai-tutor.git
cd adaptive-ai-tutor
```

### 2. Install frontend dependencies

```bash
npm install
```

### 3. Start the application

```bash
npm run dev
```

Open the local URL displayed in your terminal (usually `http://localhost:5173`).

### 4. Run tests

```bash
npm test
npm run build
```

> The current frontend can run independently. The Python AI backend and ANN integration are separate development milestones.
